How MicroBias Watermarker Works

DCT Steganography

Our technology uses Discrete Cosine Transform (DCT) steganography to embed 1-bit bias flags in images generated by Stable Diffusion. The bias flag is encoded in the mid-frequency coefficients of 8x8 DCT blocks, following JPEG compression standards.

LoRA Fine-tuning

We fine-tune Stable Diffusion using Low-Rank Adaptation (LoRA) to learn how to embed bias flags during image generation. The model is trained with a custom loss function that combines standard diffusion loss with steganographic loss.

Browser Detection

The bias detection runs entirely in the browser using WebAssembly for high-performance DCT operations. Images are processed in real-time to extract embedded bias flags with confidence scores.

Technical Specifications

  • Model: Stable Diffusion v1.5 with LoRA fine-tuning
  • Embedding: 1-bit flag in DCT mid-frequency coefficients
  • Block Size: 8x8 pixels (JPEG standard)
  • Detection Time: <16ms for 640x480 images
  • Browser Support: Chrome, Firefox, Safari with WebAssembly
  • Accuracy: >90% on generated images

Ethical Considerations

This technology is designed for defensive security research and bias detection in AI systems. It should be used responsibly to help identify and understand bias in AI-generated content, not for malicious purposes. All generated content should be clearly labeled as AI-generated.
